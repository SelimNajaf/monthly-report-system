## LAYİHƏ

**Monthly Report Studio** — `C:\Users\Admin\Desktop\Monthly-Report-Auto`
Python 3.11+, tək operator, tək Windows maşını, server yoxdur.

İngiliscə NDT (qeyri-dağıdıcı yoxlama) hesabatlarını → azərbaycanca aylıq rəsmi PDF +
JSON sidecar-a çevirir → **E-Keyfiyyet** dövlət portalına Playwright ilə göndərir.

Boru xətti: **topla (SMB) → oxu → qruplaşdır → hesabat → portal.**

Stack: PyMuPDF (PDF oxuma), python-docx, ReportLab (PDF render), PyYAML, Playwright,
PySide6 (GUI), pytest. **DB yoxdur** — durable state JSON fayllarıdır.

Repo-da `PROJECT_CONTEXT.md` var (32 bölmə, evidence-based) — Claude Code onu oxuyur.
